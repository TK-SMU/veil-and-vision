# Veil & Vision — submission

Submit the complete VeilVision_Submission.zip. Extract the entire folder before running.

## Requirements

Python 3.10 or newer with Tkinter. No pip packages, API keys or internet services are needed. Tested on macOS with Python 3.13; Windows and Linux have not been verified. Audio and font support may vary by operating system.

## Start

Mac/Linux: `python3 main.py`

Windows: `py main.py`

On Mac, the included `run_veil_vision.command` also launches the app. The .app is a launcher and does not bundle Python.

Keep all Python modules, images and the assets folder together. The download starts with an empty diary. Your working folder's saved data is preserved.

## Demo

Start → Customize → select an intention → reveal three cards → Your Cards → Card Meaning → Overall Reading → Little Step → Save → Moon Diary → Follow-up.

Choose one intention before continuing; the question is optional. Readings saved without a Little Step open the choice page when selected in Moon Diary.

Development scripts, historical reports and test screenshots have been removed from this submission folder. Credits, font licenses and reconstruction notes remain included.
